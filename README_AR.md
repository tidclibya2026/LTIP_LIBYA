# LTIP — المنصة الوطنية للاستثمار السياحي (نسخة React كاملة)

## التثبيت في Windows
1. أوقف خادم التطوير القديم باستخدام Ctrl+C.
2. احتفظ بنسخة احتياطية من مجلد `D:\LTIP_LIBYA_2026\05_PLATFORM\ltip-web` الحالي قبل استبداله.
3. فك ضغط الحزمة وانسخ **محتويات** `LTIP_React_Complete_v1` إلى `D:\LTIP_LIBYA_2026\05_PLATFORM\ltip-web` (لا تضع المجلد داخل نفسه).
4. افتح Terminal داخل مجلد `ltip-web` وشغّل:

```powershell
cd D:\LTIP_LIBYA_2026\05_PLATFORM\ltip-web
npm.cmd install
npm.cmd run dev
```

5. افتح `http://localhost:5173`.

## المحتويات
- `src/App.jsx`: الواجهة والخريطة والبحث.
- `src/App.css`: التصميم الأزرق والذهبي.
- `src/index.css`: ملف CSS نظيف، بديل لملف Vite الافتراضي المرسل.
- `public/data/zones_141.geojson`: حدود 141 منطقة، تحتوي على 145 جزءًا مضلعًا.
- `package.json`: جميع تبعيات المشروع.

## تنبيهات
- هذه حزمة مصدرية كاملة وليست نسخة مثبتة: مجلد `node_modules` ينشأ بواسطة `npm.cmd install` ويتطلب الإنترنت أول مرة.
- بلا خادم بيانات خلفي أو قاعدة PostGIS في هذه المرحلة.
- خريطة OpenStreetMap الأساسية تحتاج الإنترنت.
- حدود المناطق من بيانات المشروع السابقة، ولا تعني اعتمادًا مساحيًا أو قانونيًا.
- المدن والمطارات والموانئ والطرق لم تُربط بعد، ولا تُعرض درجات استثمارية.
